Полная инструкция ↗

Windows

Установи Python 3.9+ x64, если его ещё нет. Распакуй архив через «Извлечь всё» и открой Start.cmd. Оставь консоль открытой во время работы.

Mac

Установи Python 3.9+, если его ещё нет. Распакуй ZIP, перенеси QuizLens.app в «Программы» и открой. Страница захвата появится в браузере.

В QuizLens 1.9 и новее можно включить автообновление между занятиями в запущенном приложении. Для перехода с 1.8 один раз запусти новую версию из архива.

Читать квиз из вкладки

Для Chrome и Edge. Подключение работает с QuizLens 1.8 и новее. Если приложение уже запущено, нажми в нём «Показать папку расширения». Эту папку можно сразу выбрать в браузере.

Скачать расширение ZIP ↓
  1. Если скачал отдельный ZIP, распакуй его в постоянную папку. Открой chrome://extensions или edge://extensions.
  2. Включи «Режим разработчика», нажми «Загрузить распакованное расширение» и выбери папку browser-extension с файлом manifest.json.
  3. В QuizLens нажми значок расширения → «Подключить QuizLens». Затем во вкладке квиза нажми тот же значок → «Читать вопросы».

Компоненты для твоего режима

Для запуска нужен Python. Остальное зависит от того, как ты читаешь вопросы и получаешь ответы.

Python

Запускает QuizLens на компьютере. Если подходящий Python уже есть, можно сразу открыть приложение.

LM Studio

Нужен для ответов локальной модели по твоим документам. Загрузи модель, включи Model Server → Status и нажми в QuizLens «Проверить подключение».

Распознавание окна

На Windows запусти QuizLens и нажми «Установить OCR». Приложение подготовит Tesseract и языки. На Mac распознавание встроено в систему.
