Определяем процессор и память…

Можно подобрать модель для другого компьютера. Укажи известные характеристики. Измерить скорость получится на самом устройстве.

Где посмотреть память?

На Mac открой меню Apple → «Об этом Mac». В Windows нажми Ctrl+Shift+Esc и открой «Производительность». Объём ОЗУ указан в «Память», выделенная видеопамять — на странице графического процессора.

    Как скачать и подключить модель
    1. Открой Bionic или установи LM Studio ↗. В каталоге локальных моделей введи название выше и выбери указанный файл GGUF. Обозначение Q4_K_M в имени указывает на компактную версию модели. Если каталог недоступен, скачай этот файл по ссылке в браузере.
    2. Открой чат, выбери скачанную модель и загрузи её. В Bionic включи Settings → Local Model API → Local API server. В LM Studio открой Developer → Start Server.
    3. На компьютере, где загружена модель, открой автоматический подбор, нажми «Обновить список» и выбери модель. Проверка отправит ей три текстовых вопроса на этом компьютере.

    Для файла, скачанного в браузере, в LM Studio доступна команда lms import. Инструкция по импорту ↗
