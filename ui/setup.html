LM Studio и локальная модель

QuizLens читает окно и находит выдержки из лекций. LM Studio или Bionic запускает на твоём компьютере модель, которая выбирает ответ по этим выдержкам.

  1. Установи приложение

    На странице загрузки открой блок Download LM Studio и выбери свою систему. Уже пользуешься Bionic с локальной моделью? Переходи к серверу.

    Скачать LM Studio ↗

  2. Загрузи модель

    Подбери модель для своего компьютера. Найди её в Discover в LM Studio или в Settings → Explore в Bionic. Скачай рекомендованный файл и выбери модель в чате.

    Подобрать модель

  3. Включи локальный сервер

    LM Studio
    Developer → Start Server

    Bionic
    Settings → Local Model API → Local API server

    Проверить подключение

Определяем процессор и память…

Можно подобрать модель для другого компьютера. Укажи известные характеристики. Измерить скорость получится на самом устройстве.

Где посмотреть память?

На Mac открой меню Apple → «Об этом Mac». В Windows нажми Ctrl+Shift+Esc и открой «Производительность». Объём ОЗУ указан в «Память», выделенная видеопамять — на странице графического процессора.
