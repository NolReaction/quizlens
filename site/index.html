Ответ на квиз из твоей лекции.

Выбери окно с вопросом. QuizLens прочитает варианты, найдёт подходящий фрагмент лекции и покажет подсказку. Всё обрабатывается на твоём компьютере.

Precision — доля верных предупреждений среди всех предупреждений модели.

30 ÷ 40 = 0,75

Полная инструкция ↗
Установить на Mac

Распакуй ZIP, перенеси QuizLens.app в «Программы» и открой. Нужен Python версии 3.9 или новее. Если он ещё не установлен, скачай Python для macOS. Сайт Python ↗

Откроется локальная страница QuizLens в браузере. Её также можно открыть из меню QuizLens в строке меню. При первом захвате macOS может попросить доступ к записи экрана. Разрешение выдаётся приложению, которое выполняет захват.

Установить в Windows

Распакуй ZIP через «Извлечь всё». Установи 64-разрядный Python 3.9+ и открой Start.cmd. Оставь консоль открытой во время работы. Python для Windows ↗

Для чтения экрана закрой QuizLens, установи Tesseract с языками rus и eng, затем запусти Install-OCR.cmd. После установки снова открой Start.cmd. Пошаговая инструкция есть в START-HERE.txt внутри архива.

Выбрать локальную модель

На главной странице QuizLens открой «Подобрать модель для компьютера». Приложение учтёт память и графику, покажет точный файл GGUF и даст ссылку на скачивание. Введи характеристики вручную, если подбираешь модель для друга.

Загрузи модель в Bionic или LM Studio, включи локальный API-сервер и нажми в QuizLens «Обновить список» → «Проверить на трёх вопросах». Замер покажет, на сколько вопросов модель верно ответила за 15 секунд на вопрос. Для встроенных карточек модель можно пропустить. LM Studio ↗

Проверить захват и добавить свои лекции

В разделе «Захват» отметь демонстрационный банк analytics-demo.quiz.json. Нажми «Открыть пробный квиз», вернись в QuizLens и через «Выбрать окно» подключи вкладку квиза. Перейди в квиз и нажми «Начать».

Для занятия добавь свои PDF, PPTX, IPYNB или текст через «Лекции и модель» → «+ Добавить». При появлении подсказки можно сверить её с цитатой. В тренировке доступны вопросы с таймером, а в журнале можно разобрать и исправить ответ.
