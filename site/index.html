Установить на Mac

Распакуй ZIP, перенеси QuizLens.app в «Программы» и открой. Нужен Python версии 3.9 или новее. Если он ещё не установлен, скачай Python для macOS. Сайт Python ↗

Откроется локальная страница QuizLens в браузере. Её также можно открыть из меню QuizLens в строке меню. При первом захвате macOS может попросить доступ к записи экрана. Разрешение выдаётся приложению, которое выполняет захват.

Установить в Windows

Распакуй ZIP через «Извлечь всё». Установи 64-разрядный Python 3.9+ и открой Start.cmd. Оставь консоль открытой во время работы. Python для Windows ↗

Для чтения экрана закрой QuizLens, установи Tesseract с языками rus и eng, затем запусти Install-OCR.cmd. После установки снова открой Start.cmd. Пошаговая инструкция есть в START-HERE.txt внутри архива.

Подключи локальную модель

В QuizLens открой «Настроить LM Studio». Сравни модели по объёму памяти, числу параметров и размеру контекста. Скачай подходящий файл GGUF.

Включи сервер в LM Studio → Developer или в Bionic → Settings → Local Model API. В QuizLens проверь соединение и нажми «Выбрать для захвата».

Скачать LM Studio или Bionic ↗

Добавь документы

На странице «Захват» нажми «Добавить документ». Подойдут конспект в PDF, слайды в PPTX или блокнот IPYNB.

Отметь файлы по теме занятия. Когда появится вопрос, QuizLens поищет в выбранных документах фрагмент, который подтверждает ответ.

Выбери окно квиза

Для репетиции нажми «Открыть пробный квиз». Вернись в QuizLens, нажми «Выбрать окно» рядом с предпросмотром и укажи появившийся квиз. Когда всё готово, нажми в нём «Начать».

Для подготовки без таймера открой «Тренировка» → «Открыть карточки». Готовые карточки доступны без модели.
