# QuizLens · руководство для Mac и Windows

QuizLens читает вопрос в выбранном окне, ищет ответ в отмеченных тобой документах и показывает варианты вместе с цитатой. На странице «Захват» сначала подключи локальную модель, затем добавь документы и выбери окно с вопросами.

| Куда зайти | Что можно сделать |
|---|---|
| **LM Studio** | Установить LM Studio или подключить Bionic, подобрать файл модели под память компьютера и проверить её на трёх вопросах. |
| **Захват** | Выбрать модель и документы, подключить вкладку до начала квиза, получить подсказку и открыть её поверх окон. |
| **Тренировка** | Повторять учебные карточки, решать вопросы с таймером, менять условия и измерять скорость и точность модели. Здесь же открываются графики и таблицы. |
| **Журнал** | Вернуться к распознанному вопросу, разобрать конкретный вариант и сохранить исправление. |

## Где скачать

Открой страницу загрузки QuizLens по ссылке, которую дал автор. Она предложит архив для твоей системы. Если открыл ссылку с телефона или готовишь установку для другого компьютера, выбери нужную платформу вручную. На странице репозитория те же файлы лежат в **Releases → Latest → Assets**. Для установки скачай **QuizLens-Mac.zip** или **QuizLens-Windows.zip**. Архив **Source code** предназначен для разработки.

## Первый запуск на Mac

Готовая сборка GitHub Releases рассчитана на macOS 14 или новее, Apple Silicon и Intel. Нужен Python 3.9 или новее. Если Python ещё не установлен, скачай установщик для macOS с сайта Python. Релиз содержит готовые модули распознавания. На Intel Mac можно начать с карточек QuizLens. Для LM Studio на Mac требуется чип Apple M-серии. [Python для macOS](https://www.python.org/downloads/macos/) · [Требования LM Studio](https://lmstudio.ai/docs/app/system-requirements).

1. На странице загрузки или в описании релиза посмотри статус сборки для Mac. Для обычной установки выбери выпуск с подписью Developer ID и нотарификацией Apple. Для локальной или тестовой сборки статус может быть другим.
2. Если старая копия запущена из Terminal, нажми **Ctrl+C** в её окне. В версии с меню в строке меню выбери **«Завершить QuizLens»**.
3. Распакуй **QuizLens-Mac.zip**, перетащи **QuizLens.app** в **Программы** и открой его. Появится страница `http://127.0.0.1:8765`. Для возврата к ней используй **«Открыть QuizLens»** в меню приложения.
4. При первом запуске macOS может попросить подтвердить открытие приложения из интернета. При выборе окна отдельно появится запрос на доступ к записи экрана. Разрешение можно проверить в **Системные настройки → Конфиденциальность и безопасность → Запись экрана** (в некоторых версиях — **«Запись экрана и системного аудио»**). Для захвата вкладки дай доступ браузеру, для нативного захвата — приложению, которое названо в системном запросе.

Если macOS сообщает, что не может проверить разработчика, сверь статус релиза и заново скачай нотарифицированную сборку, когда она появится. При сообщении о повреждении или вредоносном ПО останови запуск и сообщи автору название релиза и текст ошибки. [Как macOS проверяет загруженные приложения](https://support.apple.com/102445).

## Первый запуск в Windows

1. Распакуй **QuizLens-Windows.zip** в обычную папку на диске. Запусти **Start.cmd**. Нужен установленный 64-разрядный Python версии 3.9 или новее. Подбор модели и тренировка по тексту доступны сразу. [Python для Windows](https://www.python.org/downloads/windows/).
2. Для чтения окна на Windows установи **Tesseract OCR** с английским и русским языками (`eng` и `rus`). Следом открой **Install-OCR.cmd** из распакованной папки. После установки перезапусти **Start.cmd**. Инструкцию по установке Windows-версии Tesseract публикует проект. [Установка Tesseract](https://tesseract-ocr.github.io/tessdoc/Installation.html).
3. Открой **«Проверить модель и OCR»** в разделе захвата и прогони распознавание. Для работы с вкладкой квиза используй Chrome или Edge. В Windows приложение читает изображение из выбранного в браузере источника. Во время работы держи консоль QuizLens открытой.

## LM Studio и Bionic

Открой **«LM Studio»** в верхнем меню QuizLens. На этой странице есть ссылка на установщик, подбор модели и проверка соединения. Если у тебя в Bionic или LM Studio уже отвечает Qwen, сразу переходи к включению сервера.

- **Установка.** Скачай LM Studio для своей системы из блока **Download LM Studio**. Bionic тоже умеет запускать локальные модели. Для работы локально достаточно одного из этих приложений. [Официальная загрузка](https://lmstudio.ai/download).
- **Поиск модели.** Открой **Discover** в LM Studio или **Settings → Local Models → Explore** в Bionic. Для поиска скопируй название из рекомендации QuizLens. Скачай указанный вариант GGUF и выбери его в чате. В Bionic выбери локальную модель на своём компьютере. [Поиск в LM Studio](https://lmstudio.ai/docs/app/basics/download-model) · [Локальные модели Bionic](https://lmstudio.ai/docs/bionic/models/download-local-models).
- **Включение сервера.** В LM Studio открой **Developer → Start Server**. В Bionic открой **Settings → Local Model API**, включи **Local API server** и дождись **Running**. Оставь приложение открытым. По умолчанию QuizLens обращается к серверу на этом компьютере по адресу `http://127.0.0.1:1234/v1`. [Настройка сервера](https://lmstudio.ai/docs/developer/core/server).
- **Проверка ответа.** Нажми **«Проверить подключение»** в QuizLens. Если появилось имя модели, значит сервер вернул список. Выбери текстовую модель и нажми **«Проверить на трёх вопросах»**, чтобы измерить время настоящих ответов и увидеть число верных решений. Затем нажми **«Выбрать для захвата»**.

### Какую модель скачать

1. Открой **«LM Studio» → «Подобрать модель»**. В разделе **«Этот компьютер»** появятся система, процессор и доступные сведения о памяти. Для другого компьютера нажми **«Указать характеристики»**. Для Apple M-серии укажи общий объём памяти. Для отдельной видеокарты укажи отдельно оперативную память компьютера и выделенную память видеокарты. В Windows эти значения есть в **Диспетчере задач → Производительность → Память / GPU**. Если видеокарта отсутствует в отчёте, её данные можно ввести вручную.
2. Сравни предложенные модели. Для каждой указан размер файла GGUF. Число параметров описывает размер модели. Например, **4B** означает «около четырёх миллиардов параметров». **Контекст** показывает, сколько токенов суммарно вмещают запрос и продолжение. **Лимит ответа** — отдельное ограничение на длину генерации, если его опубликовал разработчик. В разделе **«Каталог моделей»** можно посмотреть другие варианты и перейти к описанию разработчика.
3. Если Bionic или LM Studio уже показывает подходящую модель, переходи к проверке. Для новой найди её через каталог приложения или скачай конкретный **GGUF** по ссылке из рекомендации. **Q4_K_M** обозначает вариант сжатия. Размер на диске и память во время работы различаются. Для коротких вопросов начни с контекста около 4096 токенов. В классическом LM Studio скачанный отдельно GGUF можно импортировать командой `lms import "путь-к-файлу.gguf"`, если команда `lms` установлена. [Импорт GGUF в LM Studio](https://lmstudio.ai/docs/cli/local-models/import).
4. После проверки сравни число правильных ответов и время первого запроса. Замер включает поиск по документам и ответ на готовый текст. В живом захвате ожидание самой модели ограничено примерно 10 секундами, остальное время нужно на распознавание и выбор ответа.
5. Нажми **«Выбрать для захвата»**, когда решишь, какую модель использовать. Для проверки всего пути с картинкой открой **«Проверить модель и OCR» → «Проверить OCR и ответ»**. Если проверишь две модели, появится таблица **«Сравнение на этом компьютере»**. В ней видны число верных ответов за 15 секунд и среднее время двух запросов после первого. Браузер хранит последний завершённый замер для каждой из пяти последних проверенных моделей. Три коротких задания дают ориентир. Скорость и качество на твоих лекциях удобнее проверить в разделе «Тренировка».

При пересылке другу достаточно дать архив его платформы и эту инструкцию. В архив входят приложение и демонстрационные материалы. Готовые карточки можно решать без модели. Свои лекции друг добавляет на своём компьютере. Установленные модели, журнал и настройки каждый хранит у себя. Архив Windows предназначен для x64. Проверь требования LM Studio к системе, если устанавливаешь его впервые. [Системные требования LM Studio](https://lmstudio.ai/docs/app/system-requirements).

### Как читать числа токенов

На вход модели QuizLens передаёт инструкцию, вопрос, варианты и несколько подходящих фрагментов документов. Токены — части текста, которыми считает модель. Число входных токенов зависит от длины вопроса и найденных фрагментов. На выходе модель возвращает короткий ответ с номерами вариантов и ссылками на фрагменты. В разделе **«Сколько токенов нужно QuizLens»** показан пример такого запроса. После обработки вопроса в подсказке видны входные и выходные токены. Знак **≈** означает оценку по тексту. Готовая карточка и повторный показ сохранённого результата обходятся в **0 новых токенов** модели.

## Подключи окно до начала квиза

1. На странице **«Захват»** проверь выбранную локальную модель. В блоке **«Добавь документы»** нажми **«Добавить документ»**, выбери файл и отметь нужные материалы в списке **«Источники ответов»**. QuizLens извлекает текст и делит его на фрагменты для поиска. Галочка рядом с файлом включает его в поиск, а снятие галочки исключает его из текущего поиска. Для проверки по своему конспекту можно снять галочки с учебных примеров.
2. В блоке **«Выбери окно квиза»** нажми **«Выбрать окно»** и укажи вкладку квиза, даже если там пока экран ожидания. Удобнее использовать Chrome или Edge. На Mac при первом подключении система может запросить у браузера разрешение на запись экрана.
3. Когда появится вопрос, QuizLens попробует найти формулировку и **от 2 до 8 видимых вариантов**. Оставь **«Авто»** для квиза, в котором чередуются один и несколько правильных ответов. Для каждого предложенного номера можно сверить текст и источник. Ты сам отмечаешь ответ в окне квиза.
4. Если экран тесный, открой **«Поверх окон»**. Если захват браузера приостанавливается на фоне, на Mac доступен **«Захват окна средствами macOS»** с выбором окна.
5. Для остановки чтения нажми **«Остановить»** или **«Отключить»**. Для выхода на Mac используй **«Завершить QuizLens»**, в Windows нажми **Ctrl+C** в окне запуска.

**Проверка за минуту.** В блоке документов отметь учебный банк **analytics-demo.quiz.json**. Нажми **«Открыть пробный квиз»** рядом с кнопкой выбора окна. Выбери **«Без таймера»** и режим **«От 2 до 8 вариантов»**, подключи появившееся окно, затем нажми в квизе **«Начать»**. За четыре вопроса на экране появятся 2, 3, 5 и 8 вариантов. В режиме **«Несколько ответов»** первый правильный набор — **1 и 3**. После отправки те же утверждения меняются местами, и правильными становятся **2 и 4**. Для этих карточек модель можно выключить.

### Если квиз выглядит иначе

- **Вариант обрезан или находится ниже экрана.** Покажи весь список прокруткой или уменьши масштаб страницы так, чтобы вопрос и ответы одновременно помещались в кадре. Программа может обнаружить обрыв списка по видимым признакам. Когда следующий ответ полностью скрыт, одного кадра бывает недостаточно, чтобы узнать об этом.
- **Рядом чат, меню или соседний вопрос.** Под предпросмотром нажми **«Разметить области вручную»**, обведи одной рамкой весь блок задания и выбери **«Искать внутри рамки»**.
- **Авторазметка пропускает текст.** В ручной разметке выбери число вариантов, выдели вопрос и каждый ответ в нужном порядке. Оставь место на перенос строк. Разметку можно использовать повторно при том же масштабе.
- **Формат выбора распознался неверно.** Под предпросмотром выбери **«Один вариант»** или **«Несколько вариантов»**. Для следующего смешанного вопроса верни **«Авто»**. Если условие требует ровно два ответа, программа проверяет количество. При отсутствии точного числа модель может пропустить подходящий вариант.

## Тренировка и проверка модели

Для повторения без таймера открой **«Тренировка»**, выбери **«Материал для занятия»** и нажми **«Открыть карточки»**. Ответь про себя и нажми **«Показать ответ»**. На обороте увидишь правильный вариант или несколько вариантов, пояснение и, при наличии, фрагмент лекции. Кнопками **«Назад»** и **«Следующая карточка»** можно пройти колоду в своём темпе. Готовая колода работает без LM Studio.

В **«Тренировка»** оставь материал **«Метрики в аналитике»** и нажми **«Решать самому»**. Доступны десять задач. На каждую даётся 15 секунд. После ответа в поле **«Измени одно условие»** выбери новую величину или формулировку и нажми **«Решить ещё раз»**. Увидишь, как изменились правильный ответ и его объяснение. Повтор одного вопроса не увеличивает результат серии.

Например, когда 30 предупреждений из 40 верны, Precision равен 75 %. Если при тех же 30 верных общее число предупреждений выросло до 50, ответ становится 60 %.

**Для замера модели** выбери её и нажми **«Проверить модель»**. Результат показывает, на скольких вопросах за 15 секунд совпал весь набор ответов. Отсчёт идёт от показа готового текста и включает поиск по лекции и ответ модели. Для измерения OCR открой **«Проверить модель и OCR» → «Проверить OCR и ответ»** на странице захвата. Перед занятием имеет смысл прогнать один тест на своём компьютере и оставить модель загруженной.

**Для другой лекции** выбери её в поле **«Материал для занятия»**, укажи модель и нажми **«Подготовить вопросы»** в разделе **«Карточки по своей лекции»**. Сверь условия, ответы и цитаты, исправь ключи при необходимости и нажми **«Сохранить проверенные»**. После этого можно решать их самому или проверять на них модель. Ответы из твоего журнала в замере модели не используются.

## Разбор и исправление ответа

В **«Журнал»** выбери вопрос или открой его ссылкой из подсказки. Запись содержит распознанный текст в экранном порядке, исходную подсказку, выдержки, если они есть, и время обработки. Длительность подтверждения кадра отсчитывается от первого подходящего наблюдения. Она не учитывает время до появления первого читаемого кадра. Если текст менялся, раскрой **«Что видел OCR до ответа»**. Здесь показаны до четырёх последних распознаваний. По ним видно, какие строки пропадали или менялись.

В разделе разбора выбери конкретный вариант. Например, для ответа Precision на вопрос о пропущенных случаях можно увидеть, какая часть лекции объясняет различие с Recall. Авторские пояснения из готовых карточек доступны локально. Для нового вопроса можно выбрать Qwen. Если материала недостаточно, программа сообщит об этом.

Раскрой **«Исправить и сохранить ответ»**, отметь правильные пункты и нажми **«Сохранить карточку»**. При таком же вопросе, наборе вариантов, режиме и выборе лекций QuizLens сможет применить исправление после перезапуска. Если ответы поменялись местами, их номера пересчитываются. Кнопка **«Убрать мою карточку»** отменяет исправление. Удаление записи о захвате — отдельное действие.

Журнал включён по умолчанию. Его можно выключить в блоке **«Параметры чтения»** под окном квиза. На диске хранятся последние 200 записей и до 1000 сохранённых исправлений. В журнал записываются тексты и источники. Скриншоты в нём не сохраняются.

## Графики и таблицы

В **«Тренировка»** открой разбор графика или таблицы. В разделе **«Примеры»** доступны 10 заданий, включая максимум и прирост по одному графику, Precision и Recall по одной матрице ошибок. Выбери ответ — увидишь значения и расчёт. Для этого модель не требуется.

Для собственного изображения нажми **«Разобрать график или таблицу»** в захвате. При активном захвате QuizLens передаст текущий кадр на отдельную страницу. Там также можно выбрать файл или вкладку и нажать **«Взять текущий кадр»**. Через **«Обрезать кадр»** оставь график, шкалу, единицы и подписи. Если вопрос и варианты остались за пределами рамки, введи их в раскрывающемся поле.

Для автоматического ответа по изображению нужна загруженная в Bionic или LM Studio модель, которая принимает картинки. **Qwen3-4B-Instruct-2507** работает с текстом. На странице графиков выбери доступную визуальную модель и нажми **«Разобрать изображение»**. Сверь значения осей или ячеек в пояснении. Этот режим отправляет один выбранный кадр по твоей команде локальной модели. [Поддержка изображений в LM Studio](https://lmstudio.ai/docs/python/llm-prediction/image-input).

## Модели и материалы

- **Локальный сервер.** В браузере на том же компьютере можно открыть `http://127.0.0.1:1234/v1/models`. В ответе сервера появятся идентификаторы доступных моделей. [Как подключить LM Studio или Bionic и проверить ответ](#lm-studio-и-bionic).
- **Файлы.** Поддерживаются PDF, PPTX, текст и Markdown, IPYNB и банки `.quiz.json`, до 32 МиБ на файл. В блокнотах индексируется текст и код с номерами ячеек. Сканированные страницы PDF на Mac проходят распознавание. На Windows импорт PDF извлекает текстовый слой. Если PDF состоит из картинок, подготовь версию с распознанным текстом. Презентацию со слайдами-картинками удобно экспортировать в PDF.
- **Карточки.** Поле `"answer": "Recall"` задаёт один правильный вариант. Поле `"answers": ["JSON", "XML"]` задаёт набор. В **analytics-demo.quiz.json** есть примеры с разным числом ответов. Для новых формулировок QuizLens передаёт локальной модели вопрос, варианты и выдержки из выбранных лекций.
- **Поиск по смыслу.** По умолчанию работает поиск по словам. Для поиска по смыслу можно подключить локальную многоязычную embedding-модель через **«Проверить модель и OCR»** и заранее подготовить индекс.
- **Хранение.** На Mac лекции, настройки сервера и журнал находятся в `~/Library/Application Support/QuizLens/`, на новой установке Windows — в `%LOCALAPPDATA%\QuizLens`. Проверенные наборы для тренировки и настройки интерфейса сохраняются в текущем браузере. В архиве для Mac исходный код находится внутри QuizLens.app в `Contents/Resources/quiz-lens`.

## Если что-то пошло не так

| Что видно | Что проверить |
|---|---|
| Страница QuizLens не открывается | Запусти приложение, затем открой `http://127.0.0.1:8765`. В Windows оставь окно запуска открытым. |
| Список моделей пуст | Включи локальный сервер Bionic или LM Studio, открой `http://127.0.0.1:1234/v1/models` и убедись, что модель есть в списке. В QuizLens нажми **«Обновить список»**. |
| Вместо окна на Mac пустой кадр | Проверь доступ к записи экрана для приложения, которому macOS показывала запрос. Перезапусти его и заново выбери окно. |
| На Windows не читаются русские вопросы | В окне запуска или в диагностике проверь наличие русского языка Tesseract. После добавления `rus.traineddata` перезапусти QuizLens. |
| Появилось «Нет подтверждения» | Сверь распознанный текст с окном квиза, проверь порядок вариантов и отмеченные документы. Можно открыть «Журнал», сверить найденный фрагмент и сохранить исправление. |
