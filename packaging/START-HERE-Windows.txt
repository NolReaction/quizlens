QuizLens для Windows 10/11 x64

Первый запуск

1. В Проводнике нажми правой кнопкой на ZIP, выбери «Извлечь всё» и открой распакованную папку QuizLens-Windows.
2. Нужен 64-разрядный Python 3.9 или новее. Если Python ещё не установлен, возьми текущий Python 3 x64 для Windows с https://www.python.org/downloads/windows/ . После установки команда py -3 --version или python --version должна показать версию. Инструкция Python https://docs.python.org/3/using/windows.html
3. Дважды нажми Start.cmd. Оставь консоль открытой. Если браузер не открылся, введи http://127.0.0.1:8765 в Chrome или Edge. При первом запуске можно сразу открыть http://127.0.0.1:8765/setup для подбора модели под твой компьютер.
4. В QuizLens нажми «Настроить LM Studio». Если ставишь модель впервые, нажми «Подобрать модель», сравни число параметров, размер файла и запас памяти, затем скачай подходящий GGUF. Если модель уже есть, переходи сразу к серверу.
5. Открой на этом ПК LM Studio → Developer → Start Server или Bionic → Settings → Local Model API → Local API server. Стандартный адрес сервера модели — http://127.0.0.1:1234/v1 . Вернись в QuizLens, нажми «Проверить подключение», укажи модель и нажми «Выбрать для захвата».

Чтение из вкладки без установки OCR

В Chrome открой chrome://extensions, в Edge — edge://extensions. Включи режим разработчика и нажми «Загрузить распакованное расширение». На странице захвата раскрой «Читать через расширение», нажми «Показать папку расширения» и выбери показанную папку. Оставь папку на месте. Открой главную страницу QuizLens, нажми значок расширения и подключи QuizLens. Затем открой вкладку с вопросом, снова нажми значок расширения и запусти чтение. Нужные документы выбираются в QuizLens. Для картинки или отдельного приложения используй захват окна.

Чтение вопросов с экрана

1. В открытом QuizLens нажми «Установить OCR». QuizLens проверит Pillow, Tesseract и языковые данные. Если Windows запросит разрешение на установку Tesseract, подтверди его.
2. Дождись сообщения о готовности русского и английского языков. Можно сразу подключать окно.
3. Если Windows не нашла winget или у компьютера нет доступа к загрузкам, открой https://nolreaction.github.io/quizlens/#components для ручной установки компонентов. Для отдельной установки библиотек Python служит Install-OCR.cmd.
4. На странице «Захват» нажми «Добавить документ» и выбери свой конспект или презентацию. Раскрой «Управлять источниками» и отметь файлы по теме квиза. В этом меню можно просмотреть текст и удалить свой документ. Только в этих документах QuizLens будет искать подтверждение ответа.
5. В блоке «Выбери окно квиза» нажми «Выбрать окно» и укажи вкладку с вопросами. Для первой репетиции отметь среди документов analytics-demo.quiz.json, нажми «Открыть пробный квиз», затем выбери его окно в QuizLens. Нажми «Начать» в окне пробного квиза.

Что входит в архив

• Подбор модели, текстовая проверка и встроенные тренировочные вопросы запускаются сразу после установки Python. Для проверки скорости модели потребуется работающий локальный сервер с моделью.
• Для распознавания текста в выбранном окне нужны Pillow и Tesseract. Для PDF с текстовым слоем используется pypdf или pdftotext. Если PDF содержит только изображения, предварительно распознай текст или экспортируй текстовую версию. TXT, Markdown, PPTX с текстом и IPYNB открываются сразу.
• В архив входят программа и общие учебные примеры. Свои лекции можно добавить на странице захвата. Они и журнал будут лежать в %LOCALAPPDATA%\QuizLens. Новую версию можно распаковать в отдельную папку.
• В Windows окно или вкладку выбирают через браузер. В macOS есть отдельная сборка с нативным захватом и Apple Vision.

Обновления

Открой верхнее меню «Настройки» → «Обновления». Можно включить автоматическую установку между занятиями или обновиться вручную. В версии 1.9.0 этот блок находится внизу экрана захвата. Переход с версии 1.8.0 требует одного обычного запуска новой сборки.
