# QuizLens

QuizLens читает вопрос и варианты ответа в выбранном окне, ищет подходящий фрагмент лекции и показывает подсказку с источником. Можно заранее подключить вкладку, тренироваться с таймером или разобрать спорный ответ после занятия. Распознавание, поиск и работа с локальной моделью выполняются на твоём компьютере.

## Скачать

В репозитории открой **Releases → Latest → Assets**. Если автор указал страницу загрузки в **About → Website**, там можно выбрать платформу и прочитать инструкцию по первому запуску.

| Компьютер | Файл релиза | Первый запуск |
|---|---|---|
| macOS 14+, Apple Silicon или Intel | `QuizLens-Mac.zip` | Выбери нотарифицированный выпуск, распакуй архив, перетащи `QuizLens.app` в «Программы» и открой его. Нужен Python 3.9+. |
| Windows 10/11 x64 | `QuizLens-Windows.zip` | Установи 64-разрядный Python 3.9+, распакуй архив и открой `Start.cmd`. Для распознавания экрана следуй `START-HERE.txt` из архива. |

Статус подписи Mac указан для каждого выпуска отдельно. Содержимое архивов и обновление уже установленной версии описаны в [руководстве пользователя](docs/GUIDE.md).

## Попробовать за несколько минут

1. После запуска откроется локальная страница QuizLens. Перейди в **«Тренировка» → «Решать самому»**, чтобы познакомиться с приложением на готовых заданиях. Этот режим работает без модели.
2. Для ответов по своим лекциям нажми **«Подобрать модель для компьютера»**. QuizLens предложит конкретный файл GGUF, поможет подключить модель в Bionic или LM Studio и проверит на трёх вопросах, укладывается ли она в 15 секунд.
3. На странице **«Захват»** открой **«Лекции и модель»**, добавь файл лекции и нажми **«Выбрать окно»**. Можно выбрать вкладку до появления первого вопроса. Для репетиции в приложении есть **«Открыть пробный квиз»**.

Поддерживаются PDF, PPTX с текстом, TXT, Markdown, блокноты IPYNB и готовые банки вопросов. Приложение распознаёт от двух до восьми видимых вариантов, включая задания с несколькими ответами. Ответ можно проверить по приведённой цитате. В журнале сохраняются тексты, источники и исправления. Изображения экрана в журнал не записываются.

## Для разработчиков

Сервер и поиск написаны на Python, интерфейс — на JavaScript. На macOS используются Swift, Apple Vision и ScreenCaptureKit. В Windows распознавание обеспечивает Tesseract. Инструкции по запуску из исходников, тестам, публикации страницы и выпуску архивов собраны в [руководстве по публикации](docs/PUBLISH.md). Для сборки с Developer ID есть отдельная [инструкция для macOS](docs/MAC-SIGNING.md).
